# چندزبانه‌سازی

زبان‌های فعال در `frontend/config/params.php` تعریف می‌شوند. زبان عمومی و پنل از `APP_LANGUAGE` و `ADMIN_LANGUAGE` خوانده می‌شوند.

## افزودن زبان

1. کد، locale، عنوان، جهت و fallback را به آرایه `languages` اضافه کنید.
2. فایل `frontend/messages/<yii-locale>/app.php` را بسازید.
3. ترجمه محتوای دیتابیسی را از پنل وارد کنید.
4. مسیر، RTL/LTR، انتخاب‌گر زبان و `hreflang` را آزمایش کنید.

رشته رابط باید با این الگو ترجمه شود:

```php
Yii::t('app', 'Message key')
```

کلید ترجمه را پویا نسازید؛ ابزار تشخیص ترجمه‌های استفاده‌نشده باید بتواند آن را در سورس پیدا کند.

## مسیرها و محتوا

صفحات عمومی با پیشوند زبان مانند `/fa/about` و `/en/about` تولید می‌شوند. مسیرهای مدیریت زبان عمومی ندارند و از زبان مستقل پنل استفاده می‌کنند. اگر ترجمه محتوایی موجود نباشد، زبان fallback نمایش داده می‌شود.

برای هر زبان، عنوان صفحه، توضیحات SEO، canonical و `hreflang` را بازبینی کنید. ترجمه ماشینی بدون بازخوانی انسانی وارد نسخه نهایی نشود.

محتوای اسلایدهای Carousel شامل عنوان، متن بالای عنوان، متن اصلی و برچسب دو دکمه نیز از فرم مدیریت اسلاید قابل ترجمه است. نشانی دکمه‌ها و تصویر بین زبان‌ها مشترک می‌مانند. اگر ترجمه‌ای خالی باشد، مقدار زبان پیش‌فرض مطابق زنجیره fallback نمایش داده می‌شود.
